# Campus Connect (Draft)

CS5910 System Design and Implementation — Julio Larrea, Muiz M. Onifade, Pavel Clarke.

Contains the MySQL database schema, generated project data for every table, and a working login screen.

## Run it

Requires Node.js 18+ and MySQL 8.0+.

```bash
npm install
# Create a MySQL user for the app (once):
sudo mysql -e "CREATE USER 'campus'@'localhost' IDENTIFIED BY 'campus'; GRANT ALL ON campus_connect.* TO 'campus'@'localhost';"
npm run db:setup   # creates the campus_connect database and loads all the data
npm start          # http://localhost:3000
```

Connection settings come from environment variables (`DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`); see `.env.example`.
To put it online on Amazon Lightsail, see [DEPLOY-LIGHTSAIL.md](DEPLOY-LIGHTSAIL.md).

You can also load the database without Node, e.g. in MySQL Workbench or the `mysql` client:

```bash
mysql -u root -p < db/Database_schema.sql
mysql -u root -p campus_connect < db/Project_data.sql
```

## Project data

`db/Project_data.sql` is generated by `npm run db:generate` (`db/generate-data.js`). The data is consistent with the schema's rules:
no faculty member or room is double-booked, students have no time clashes, every enrollment meets its prerequisites,
classes never exceed capacity, and `available_Seats` matches the enrollment count.

| What | Rows |
|---|---|
| Users / logins | 261 (220 students, 36 faculty, 3 admins, 2 statistics dept) |
| Departments / majors / minors | 6 / 12 / 6 |
| Courses / prerequisites | 90 / 96 |
| Semesters | 6 (Fall 2024 – Spring 2027; Fall 2026 is current) |
| Classes (sections) | 684 |
| Enrollments / student history | 2,333 / 1,654 |
| Attendance (Fall 2026 so far) | 6,611 |

`db/sample-queries.sql` has example queries (a student's schedule and transcript, holds, attendance, …).
